### 1.4 apps/api — platform foundation (ADR-025: infra **before** controllers)
All 10 API platform requirements implemented and unit-tested (67 tests):
1. Middleware/Guards/Filters/Validation/Logging/OTel/RequestContext in place
   before any business controller.
2. **RFC 9457 Problem Details** as the only error shape (25-code table,
   `TENANT_VIOLATION` masked as 404).
3. OpenAPI auto-generation shell (swagger at `/docs`, spec at `/openapi.json`).
4. Every request carries Request/Correlation/Organization/User/Trace IDs
   (AsyncLocalStorage context + W3C span; no-op spans mint a uuidv7 fallback).
5. Guard chain: Auth (JWT HS256 + API key), Tenant isolation (+IP allowlist/CIDR),
   RBAC (`@RequiresCapabilities`), Entitlements (`@RequiresFeature`, fail-closed),
   Credits (`@RequiresCredits`).
6. Rate limiting (Redis sliding window, 8 documented buckets, `RateLimit-*` +
   `Retry-After` headers) and **PG-backed idempotency** (claim/replay, byte-identical
   responses, failures never cached).
7. Controllers call services only — foundation enforces the seam.
8. Health endpoints: `/health`, `/health/ready`, `/health/live`.
9. Prometheus `/metrics` (request histogram, route-pattern labels).
10. Request logging interceptor (pino, request-scoped bindings).

## 3. Final Architectural Decisions (normative, from ADRs)

1. **One modular monolith API + worker fleets** (NestJS 11 + Fastify 5, ADR-001/006/026).
   Extract services only on measured pain (ADR-018 stage triggers).
2. **REST /v1 public-API-first**, OpenAPI-generated SDKs (ADR-004).
3. **Events backbone:** transactional outbox in Postgres, at-least-once delivery,
   idempotent inbox consumers, durable DLQ, replay cursors; PG is the only source
   of truth (ADR-024). Envelope v1.1 carries correlation/causation/producer/metadata.
4. **Multi-tenancy:** `orgId` is the shard key invariant (ADR-018); DB-level tenant
   scoping via client extension; violations surfaced as 404 (no existence oracle).
5. **Zero vendor lock-in:** vendor SDKs only under `**/adapters/**` or
   `**/providers/**` (machine-enforced plannedEdges + deep-import policy).
6. **Security:** RFC 9457 everywhere, session JWT + API keys, envelope-encrypted
   token vault design (ADR-007), RBAC capability algebra, fail-closed entitlements.
7. **Observability:** OpenTelemetry everywhere (ADR-021), pino logs with request
   context, Prometheus metrics endpoint.
8. **Economic guardrails:** AI cost metered in micros; plan-gated quality knobs are
   the COGS battleground (ADR-005); credits ledger blocks runs at zero (never
   surprise bills).
9. **Framework floor:** NestJS 11 / Fastify 5 / OTel 0.217 / vitest 3 — pinned by
   the security gate, not taste (ADR-026).

## 4. Technical Requirements

- **Node.js** ≥ 22.0.0 · **pnpm** 9.15.9 · **TypeScript** 5.6.3 strict
  (`exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, NodeNext).
- **PostgreSQL** 16 with `pgvector` extension.
- **Redis** 7.4 (AOF, `noeviction`) — events dedup windows, rate limiting, BullMQ.
- **Prisma** 5.22.0 (schema is byte-identical with `docs/Database.md` §3).
- **zod** 3.23.8 everywhere contracts cross a boundary.
- Runtime deps per package are declared in each `package.json`.
- Local data plane: `docker compose up -d` (Postgres, Redis, MinIO, Mailpit,
  ClamAV, Jaeger, Bull Board) — see `docs/DEVELOPER-GUIDE.md`.
